microG is an open-source project that provides some Google Play Services functions. If FrostNav lists microG as a shared package for the app you are installing, choose the option to install the missing packages together. See [App Management](../kullanim/apps.mdx) for details.

## Grant permissions from Self-Check

1. On the vehicle screen, open **microG Settings → Self-Check**.
2. Under **Permissions granted**, tap the missing permission needed for the feature you want to use.
3. If Android prompts you, tap **Allow**. If no prompt appears, grant the permission under **Settings → Apps → microG Services → Permissions**.
4. Return to **Self-Check** and make sure the row is checked.

## Sign in to your Google Account

1. Connect your vehicle’s multimedia system to the internet and open **microG Settings**.
2. Open **Google Account** and tap **Add account**.
3. Sign in on Google’s sign-in screen and complete two-step verification if enabled.
4. Return to microG Settings and check that your account appears. Then follow the steps in the [Google Maps](./google-maps.mdx) guide.
