FrostNav is a free app. You install it on the multimedia screen of your Chery car. You use a web browser to install it.

Select your car first. The vehicle heading tells you if you need `adbauth.key`.

## Step 1: Select your vehicle {#arac-sec}

The wizard below finds out with a few questions whether you need an `adbauth.key`. If you do, it also shows how to get the Product ID.

## Step 2: Find your software version

1. Open "Settings" (local settings) on the car screen.
2. Touch "System" in the left menu.
3. Scroll to the bottom of the page.
4. Read the last line. It shows "DMC yazılımı sürüm numarası" and the version number. Example: `DMC yazılımı sürüm numarası 02.00.00`.

:::note

The word "DMC yazılımı sürüm numarası" is in English, also when the car language is Turkish.

On a Jaecoo, the version is on the `Versiyon bilgisi` (Version info) line of the System page. Example: `02.00.12`. Details: [Jaecoo](./araclar.mdx#jaecoo).

:::

## Step 3: Select the correct guide

| Your software version | Guide | Install type in the web installer |
|---|---|---|
| Exactly **02.00.00** | [Install for 02.00.00](./02-00-00.mdx) | "02.00.00" |
| Higher than **02.00.00** (ADB Lock) | [Install for ADB Lock](./adb-kilid.mdx) | "I have adbauth.key" |

:::warning

Do not select the wrong guide. The install does not complete.

:::

The web installer is at [https://frostnav.com/install](https://frostnav.com/install). It needs JavaScript and WebUSB. These guide pages do not need JavaScript.
