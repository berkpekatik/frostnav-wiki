Drive Memory saves the drive mode you choose. Each time the car starts, the app sets that drive mode again. You do not choose the mode by hand.

## Open the screen

1. Open the FrostNav app.
2. Touch "Drive Memory" in the side menu.
3. On the full-screen home, touch the "Mode" status on the vehicle card. That status opens the same screen.

## Drive modes

Eco, Normal, and Sport appear first. Check "4x4 modes" to also show Snow, Mud, Offroad, and Sand. Your car may have fewer modes than the list.

| Option | Meaning |
|---|---|
| None | No automatic change. This is the default. It is not shown as a card. "Clear selection" returns to this state. |
| Eco | Economy mode. |
| Normal | Normal mode. |
| Sport | Sport mode. |
| Snow | Snow mode. Visible while "4x4 modes" is checked. |
| Mud | Mud mode. Visible while "4x4 modes" is checked. |
| Offroad | Off-road mode. Visible while "4x4 modes" is checked. |
| Sand | Sand mode. Visible while "4x4 modes" is checked. |

## Set a mode

1. Open "Drive Memory".
2. Touch a mode card. The selected card is highlighted.
3. The app sends the mode to the car at once.
4. The app saves your choice.

## What happens when the car starts?

1. You start the car.
2. When the car reaches the running state, the app sets the saved mode.
3. This happens each time you start the car.

:::note

If "None" or "Eco" is selected, the app does not set the mode when the car starts. If you touch the "Eco" button, the app sets Eco once, immediately.

:::

## Stop the automatic change

1. Open "Drive Memory".
2. Touch "Clear selection".

## Features to disable at startup

Below the modes, "Features to disable at startup" is shown. The features you mark are turned off when the vehicle starts.

| Card | What turns off |
|---|---|
| Automatic engine stop | Automatic engine stop. |
| Speed limiter | The speed limiter. |
| Lane departure warning | Lane departure warning. |
| Lane keeping assistance | Lane keeping assistance. |
| Forward collision warning | Forward collision warning. |
| Automatic emergency braking | Automatic emergency braking. |
| CPD (child presence detection) | In-car child detection. It depends on the hardware and the software. It may not work on every model. |
| Rear Window Child Lock | The rear-window child lock. |

1. Touch a card. The card is marked.
2. Touch the card again to clear the mark.
3. If you mark "Forward collision warning" or "Automatic emergency braking", a warning opens. The warning says that turning the safety feature off is your responsibility. Confirm to continue.

## What you need

- The FrostNav background service must be running. In [Settings](./settings.mdx), set "Run in the background" to On.
- The installer must finish the install and grant every permission. See the [install guide](../kurulum/index.mdx).
