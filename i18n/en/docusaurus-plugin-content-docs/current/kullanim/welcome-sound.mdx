The screen title is "Welcome screen". In the side menu and on the home panel the name is "Welcome".

## First start

The first time you open the app, these windows appear:

1. **Welcome window:** It shows the legal notice and the terms of use. Read them. Touch "I accept" to continue. If you touch "I decline", the app closes.
2. **Language window:** "Choose your language to get started". Choose a language. Touch "Continue".

The legal notice says: the software is free, you change the settings by your own choice, and the developer is not responsible for damage.

## Open the screen

1. Open the FrostNav app.
2. Touch "Welcome" in the side menu. On the home panel, touch the "Welcome" shortcut.
3. Two cards appear: "Choose from USB" and "Opening design".

## Startup sound

The startup sound is an audio file the car plays. You can set it to play each time you start the car.

### Add a sound file

1. Download a sound file on a phone. The app reads these types: mp3, wav, m4a, ogg, flac, aac, wma, and amr.
2. Plug the USB stick into the car.
3. Touch the "Choose from USB" card.
4. Under "Audio files on USB", touch the file name. The app saves the file. The file name appears under "Selected sound".
5. If there is no USB stick, send the file to Downloads with [Transfer](./web-server.mdx). Touch the "Choose sound" row and find the file. If the file window does not open, the Downloads list appears.

### Play and stop

- Touch the "Play" row to listen to the sound.
- While the sound plays, the same row becomes "Stop". Touch that row again to stop it.
- If you did not select a file, the app shows "Select a sound file first".

### Play automatically at startup

1. Choose a sound file.
2. Select "Yes" for "Play automatically on startup".
3. The app plays the sound each time you start the car.
4. Select "No" to stop this.

## Entrance design

Touch the "Opening design" card. The entrance design is a picture shown on the main screen when the car starts. This picture is separate from the sound file.

### Designs

| Option | What it shows |
|---|---|
| Off | No picture at startup. This is the default. |
| Standard Welcome | A time-of-day greeting, a large clock, and the line you write. The greeting is Good morning, Good afternoon, or Good evening. |
| Winter Touch | A pink night, falling petals, moonlight, and the line you write. |
| Mountain Hike | A sunset ridge and the line you write. |
| Prestige | A carbon backdrop, a golden light sweep, time-of-day metallic tones, and the line you write. |

### Choose a design

1. Touch the "Opening design" card.
2. In "Entrance design", touch a card. The selected card is highlighted.
3. The app saves your choice.

### Custom line

1. Write one line in the "Custom line" box. The box says "First and last name".
2. The app saves the line.
3. If you leave the box empty, the name line is hidden.

### Preview

1. Touch "Preview".
2. The selected design opens on the main screen.
3. Touch the screen to close the picture.
4. If you do not touch it, the picture closes after about 4.5 seconds.

:::note

If "Off" is selected, "Preview" does not show a picture.

:::

### What happens when the car starts?

1. You start the car.
2. The app shows the selected design on the main screen.
3. Touch the screen. The picture closes.
4. If you do not touch it, the picture closes after about 4.5 seconds.

If "Off" is selected, the app does not show a picture at startup.

:::note

This picture needs the overlay permission. The installer grants it.

:::
