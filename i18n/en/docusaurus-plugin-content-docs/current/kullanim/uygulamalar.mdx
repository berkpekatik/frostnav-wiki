## Install apps

Open FrostNav and switch to **Apps → Server** mode. Select the app and tap **INSTALL**. When setup finishes, the **OPEN** button appears. If FrostNav shows a shared package prompt, choose the option to install the missing packages together. See [App Management](./apps.mdx) for details.

## Google Maps

Open Google Maps to search for an address and plan a route. Enable projection and notification access in FrostNav to show navigation cards on the instrument cluster. See the [instrument cluster guide](./projection.mdx) for the steps.

## microG

microG is an open-source project that provides some Google Play Services functions. If FrostNav lists microG as a shared package for the app you are installing, select it during setup. See the [microG project](https://microg.org/) for details.

## Yandex Maps

Open Yandex Maps to search for an address and plan a route. Enable the FrostNav accessibility service and turn on projection to show navigation on the instrument cluster. See the [instrument cluster guide](./projection.mdx) for the steps.

If the map app cannot find your location, see the GPS steps under [Known Issues](../bilinen-sorunlar.mdx).
