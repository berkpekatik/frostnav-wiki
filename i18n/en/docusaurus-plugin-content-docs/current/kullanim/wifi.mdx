Use this screen to control Wi-Fi on the car. You can turn Wi-Fi on or off, find networks, and connect to a network.

:::warning

WARNING:

Android Auto and Apple CarPlay turn Wi-Fi off. If you use one of them, Wi-Fi can go off. Come back to this screen and turn Wi-Fi on again.

:::

## Open the screen

1. Open the FrostNav app.
2. Touch "Wi-Fi" in the side menu. On the home panel, touch the "Wi-Fi" shortcut. The "Wi-Fi" status on the vehicle card also opens this screen.

## Buttons

| Button | What it does |
|---|---|
| Turn Wi-Fi on | Turns Wi-Fi on. The button text changes to "Turn Wi-Fi off". |
| Turn Wi-Fi off | Turns Wi-Fi off. |
| Refresh | Scans for networks again. The button shows "Scanning…" while it works. |

The status line shows "Connected:" and the network name. If there is no connection, it shows "Not connected".

## Connect to a network

1. Make sure that Wi-Fi is on.
2. Touch "Refresh". Wait for the list.
3. Find your network in the list. Each item shows the network name, the signal (Strong, Good, Fair, or Weak), and the security type.
4. Touch the network.
5. If the network has a password, a "Wi-Fi password" window opens. Type the password. Touch "Connect".
6. If the network is open, the car connects at once.
7. Wait for the message "Connected". The connected network is shown in a different color.

:::note

Keep the network name and the password short. Use only English letters and digits. Turkish characters, spaces, and symbols make the connection harder. One user connected after setting the network name to `0000` and the password to `12345678`.

:::

## Disconnect from a network

1. Touch the network that shows "Connected".
2. The car disconnects. A message shows the name of the network.

## Messages

| Message | Action |
|---|---|
| Wi-Fi is off; turn Wi-Fi on first | Touch "Turn Wi-Fi on". Then touch "Refresh". |
| No Wi-Fi networks found. Please scan | Touch "Refresh". Make sure that the router or phone hotspot is on. |
| Password cannot be empty | Type the password. |
| Connection failed | Check the password. Try again. Keep the network name and the password short. Use only English letters and digits. |

## Saved networks

1. Touch "Saved networks".
2. Select the networks to forget. Their passwords will be deleted.
3. Touch "Forget". The screen says how many networks were forgotten.

If there is no saved network, the window says "No saved networks." If you touch "Forget" without a selection, it says "No network selected".

If Android blocks the removal, the network was added from system settings. Forget that network from the vehicle Wi-Fi settings.
