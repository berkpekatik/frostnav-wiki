Vehicle information shows fuel, range, distance, and engine readings. This screen does not change the readings.

## Open the screen

1. Open the FrostNav app.
2. Touch "Vehicle information" in the side menu. On the home panel, touch the "Vehicle information" shortcut.

## Read the readings

1. Turn the ignition on.
2. If there is no connection, the screen says "Waiting for the vehicle. Turn on the ignition and tap Refresh."
3. Touch "Refresh". When the connection is open, the status is "Vehicle connection active".

If a reading is missing, the card shows "—". "Active only" keeps the cards that have a value.

### Filters

| Filter | What it shows |
|---|---|
| All | Every card. |
| General | Fuel, range, distance, battery, coolant, gear, and vehicle status. |
| Trip | The trip, the counters, average speed, and this trip's consumption. |
| Fuel | Fuel level, range, consumption, and the low-fuel warning. |
| Engine | Engine speed, vehicle speed, battery, coolant, and gear. |

### Cards

| Card | What it reads |
|---|---|
| Fuel level | Fuel in the tank. |
| Remaining range | Distance left on the remaining fuel. |
| Range correction | The total-range correction. |
| Total distance | The odometer. |
| Trip distance | The current trip. |
| After counter reset | Distance after the counter was reset. |
| Since vehicle start | Distance in this start. |
| Average speed | Average speed. |
| Average consumption | Average fuel consumption. |
| Average consumption this trip | Consumption for this start. |
| Fuel used summary | Fuel used. |
| Low fuel warning | Whether the warning is on. |
| Battery voltage | Battery voltage. |
| Coolant temperature | Coolant temperature. |
| Engine speed | Engine speed. |
| Vehicle speed | The measured speed. |
| Dashboard speed | The speed the cluster shows. |
| Gear | The selected gear. |
| Vehicle status | The vehicle power state. |

## Technical checks

1. Touch "Technical checks".
2. The car's EngMode app opens.

If the app is missing, the screen says "EngMode app not found". If permission is missing, it says "Could not open EngMode (permission denied)".
